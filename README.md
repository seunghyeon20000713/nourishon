# NourishOn

신체 정보와 식사 기록을 바탕으로 근거 있는 식생활 개선을 돕는 웹 서비스를 만드는 프로젝트입니다.

## 현재 준비 상태

- 기본 폴더 구조와 Python 가상환경 `.venv`를 준비했습니다.
- `.gitignore`에 가상환경, 캐시, 인증 정보 및 실제 데이터 제외 규칙을 작성했습니다.
- `backend/nutrition.py`에 100g당 영양성분과 섭취량(g)을 받아 실제 섭취한 영양성분을 계산하는 함수를 작성했습니다. 웹 서비스는 아직 구현하지 않았습니다.
- 라이브러리 설치, API 연결, 데이터베이스, Docker, 웹 화면, 챗봇 구현은 진행하지 않았습니다.
- 로컬 Git 저장소를 초기화했습니다. GitHub 저장소 연결과 첫 업로드를 준비하고 있습니다.

## 영양 계산

계산식은 `100g당 영양성분 × (섭취량(g) ÷ 100)`입니다. 1회 제공량당 값과 혼동하지 않아야 합니다.
연습용 값으로 200kcal/100g을 150g 섭취하면 300kcal입니다. 실제 식품 데이터가 아닙니다.
섭취량이 0g이면 0을 반환하고, 영양성분이나 섭취량이 음수이면 `ValueError`를 발생시킵니다.
정상값, 0g, 각 입력의 음수, 두 입력 모두 음수인 총 5개 사례를 가상환경에서 검증했습니다.
아직 결측값·숫자가 아닌 값·NaN·무한대에 대한 입력 검증과 테스트 파일은 추가하지 않았습니다.

## 폴더 구조

```text
nourishon/
├─ backend/           # 향후 백엔드 코드
├─ data/
│  ├─ raw/           # 원본 데이터 보관 위치
│  └─ processed/     # 가공 데이터 보관 위치
├─ docs/              # 기획 및 개발 문서
├─ tests/             # 향후 테스트 코드
├─ .venv/             # 로컬 Python 가상환경 (Git 제외)
├─ .gitignore
└─ README.md
```

빈 폴더에는 Git에서 폴더를 보존하기 위한 `.gitkeep`을 두었습니다.
`data/` 안의 실제 파일은 Git에서 제외하고 `raw/`, `processed/`의 `.gitkeep`만 보존합니다.

## Python 환경

Python 3.12.3으로 `.venv`를 생성했습니다. pip 및 외부 라이브러리는 설치하지 않았습니다.

```bash
source .venv/bin/activate
python --version
```

가상환경 Python은 프로젝트 기준 `.venv/bin/python`입니다.

## 데이터 및 인증 정보 관리

실제 신체 정보와 식사 기록은 `data/`에, 로컬 비밀 설정은 `.env` 등에 보관하고 Git에 올리지 않습니다.
`.env.example`을 만들 경우 실제 키나 개인정보 없이 항목 예시만 작성합니다.
`.gitignore`는 파일 내용을 검사하지 않으므로 문서나 코드에 인증키와 개인정보를 직접 작성하지 않아야 합니다.
