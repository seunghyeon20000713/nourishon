# 식약처 공공 API 첫 연결 확인

확인일: 2026-11-05. Python 3.12.3 가상환경의 표준 라이브러리로 수동 호출했습니다.
전체 수집이나 주기적 갱신이 아닌 첫 페이지 3개 항목 연결 확인입니다.

## 공식 요청 정보

- [공식 API 신청·명세 페이지](https://www.data.go.kr/data/15127578/openapi.do)
- 요청 주소: `https://apis.data.go.kr/1471000/FoodNtrCpntDbInfo03/getFoodNtrCpntDbInq03`
- 비밀값을 제외한 조건: `pageNo=1`, `numOfRows=3`, `type=json`
- 키는 로컬 `.env`의 `DATA_GO_KR_SERVICE_KEY`에서 읽었습니다. 키나 키를 포함한 요청 주소는 출력·문서·커밋에 포함하지 않았습니다.

## 인증 오류 해결

처음 호출은 HTTP 403과 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`로 거절됐습니다.
키 내용을 출력하지 않고 형식만 검사한 결과, 저장된 값이 URL 인코딩된 형태였습니다.
메모리에서 `urllib.parse.unquote()`로 디코딩한 뒤 `urlencode()`로 요청을 만들자 정상 응답을 받았습니다.
이 과정에서 `.env`는 변경하지 않았습니다. 디코딩 때는 `+`를 공백으로 바꾸는 `unquote_plus()`를 사용하지 않습니다.
네트워크 오류의 예외 문자열에는 요청 주소가 포함될 수 있으므로 그대로 출력하지 않고 상태와 알려진 오류 코드만 확인했습니다.

| 항목 | 확인 결과 |
|---|---|
| 정상 결과 코드 | 00 |
| 요청·수신 건수 | 첫 페이지 3개 |
| API가 보고한 전체 결과 수 | 341,644 |
| 항목별 필드 수 | 193개 |
| 원본 JSON 구조 | 최상위 header, body / body에 pageNo, totalCount, numOfRows, items |
| 받은 식품의 영양성분 기준량 | 3개 모두 SERVING_SIZE=100g |
| 생성 방법 | 3개 모두 분석 |

전체 결과 수는 이번 호출 시점·조회 조건의 응답 값입니다. 전체를 내려받거나 전체 데이터의 품질을 확인했다는 뜻이 아닙니다.
API가 정상 응답하더라도 개별 행의 정보가 오늘 갱신됐다는 뜻은 아닙니다.

확인한 공개 식품명은 `국밥_돼지머리`, `국밥_순대국밥`, `국밥_콩나물`입니다. 추천 식단이나 개인 식사 기록이 아닙니다.

## 로컬 보관

- 원본: `data/raw/mfds-api-page1-3-20261105-170820.json`
- 수집 기록: `data/raw/mfds-api-page1-3-20261105-170820.metadata.json`
- 수집 기록에는 인증키 없는 요청 조건, 수집 시각, 파일 해시, 요청·수신 건수와 전체 수집 미완료 표시를 넣었습니다.
- `.env`와 원본·수집 기록은 Git 제외 대상이며 업로드하지 않습니다.
