# 영양 계산 입력 검증 기록

## 목적과 범위

100g당 영양성분과 실제 섭취량(g)을 받아 `100g당 값 × (섭취량 / 100)`으로 환산합니다.
아래 숫자는 실제 식품이 아닌 연습용 값입니다. 공공 데이터 연결·목표 산출·건강 판정은 아직 구현하지 않았습니다.

## 설계 선택

- 일반 `int`와 `float`만 허용합니다. 문자열·None·참/거짓은 TypeError로 거부합니다. Python에서 bool은 int의 하위 형식이므로 별도로 제외하기 위해 정확한 형식을 확인합니다.
- 음수·NaN·무한대는 ValueError로 거부합니다. 입력을 float로 변환할 때 범위를 넘거나 계산 결과가 무한대가 되는 경우도 거부합니다.
- 0은 유효한 값이며 결측값과 구분합니다. 음수 영양성분과 0g을 함께 입력해도 오류를 감추지 않습니다.
- 영양성분 입력과 출력의 단위는 같습니다. 섭취량은 g이며, 1회 제공량당 값이나 mg 단위 섭취량을 그대로 넣지 않아야 합니다.
- 표준 라이브러리 math와 unittest를 사용해 추가 설치 없이 구현·검증합니다.
- 소수는 부동소수점 근삿값으로 계산하고 테스트에서는 소수 결과를 허용 오차로 비교합니다. 표시 반올림과 극소값 정밀도 정책은 아직 정의하지 않았습니다.

실행 환경: 프로젝트 `.venv/bin/python`, Python 3.12.3.

```bash
.venv/bin/python -B -m unittest discover -s tests -v
```

| 테스트 | 확인 내용 |

| 0 | 섭취량 0, 영양성분 0, 둘 다 0 → 0.0 |

| 형식 오류 | 양쪽 입력 각각 None, 숫자 문자열, 빈 문자열, True, False, 리스트, 딕셔너리 → TypeError |
