# 개인 프로필: 인바디 측정값 등록 계획

결정일: 2026-11-05. 사용자 요청으로 개인 상태 입력을 BMI 수치 입력 중심에서 인바디 측정값 등록 중심으로 변경합니다.
이 문서는 기능 계획입니다. 프로필 저장·입력 화면·체성분 기반 목표·식사 및 운동 추천은 아직 구현하지 않았습니다.

후속 합의에 따라 인바디는 선택 입력으로 둡니다. 기본 정보만으로도 이용할 수 있으며, 인바디가 있으면 체성분 정보를 추가 반영하는 두 경로를 제공합니다.
기본 경로도 BMI 숫자 하나만으로 목표를 정하지 않고 키·체중·나이·활동 수준·목표와 계산에 필요한 추가 정보를 사용합니다.
화면에는 ‘기본 정보 기반 추정’과 ‘체성분 정보 추가 반영’을 구분하고, 인바디 등록 시에도 영양 목표의 정확성을 보장하거나 측정값을 확정적 진단으로 표시하지 않습니다.

## 첫 입력 방식

처음에는 사용자가 측정 결과의 숫자를 직접 입력하는 방식으로 설계합니다.
검사지 사진 업로드·OCR·인바디 계정 또는 기기 연동은 별도 검토 대상으로 두며 이번 결정으로 구현하지 않습니다.

| 항목 | 단위 및 계획 |
|---|---|
| 측정일 | 측정 기록의 시점. 업로드 날짜와 구분 |
| 체중 | kg |
| 골격근량 | kg. 근육량·제지방량과 별도 항목으로 취급 |
| 체지방량 | kg |
| 체지방률 | % |
| 키 | cm. 별도 프로필 값으로 관리 |
| 측정 출처 | 사용자가 입력한 기기명·모델 등. 모르면 미입력 |
| 관리 목표·활동 수준·운동 경험·선호 | 별도 프로필 입력. 체성분 값으로 추정하지 않음 |

측정 결과에 있는 값만 등록하고 빠진 값은 결측으로 남깁니다. 필수 항목의 최종 범위와 입력 검증 규칙은 프로필 구현 단계에서 확정합니다.
같은 시점의 체중·체지방량·체지방률을 함께 확인할 수 있게 하되 서로 다른 측정일의 값을 조합하지 않습니다.
BMI는 키·체중으로 계산할 보조 지표로 유지하며, 체성분이나 건강 상태의 단독 판정 기준으로 사용하지 않습니다.

## 기록·분석 계획

- 측정 기록은 날짜별로 추가하고 과거 값을 최신 값으로 덮어쓰지 않습니다.
- 출처와 측정 조건을 기록할 수 있게 하고, 다른 시점·기기의 측정값을 같은 조건으로 간주하지 않습니다.
- 영양 목표 공식과 운동 지침은 적용 대상·출처·버전을 확인한 뒤 별도로 구현합니다. 체지방률·골격근량만으로 열량·단백질·운동 강도를 임의 산출하지 않습니다.
- 계산은 코드가 수행하고 LLM은 검증된 결과와 자료를 설명하는 역할로 제한할 계획입니다.
- 일반 성인 대상의 식사·일상 활동 개선을 우선합니다. 질환 치료식·임신·수유·미성년자·재활 운동은 첫 버전에서 제외합니다.
- 진단·체성분 측정의 임상적 해석은 이번 기능 범위에 포함하지 않습니다.

## 개인정보와 개발 순서

실제 인바디 측정값과 검사지는 개인 건강정보로 취급해 GitHub·테스트·문서·로그에 포함하지 않습니다.
예시는 가상 값으로만 작성합니다. 저장 구조에는 사용자 구분을 고려하고 인증 전에는 로컬 단일 사용자 개발용으로 제한합니다.
사진을 수집하지 않는 첫 입력 방식으로 불필요한 이름·생년월일 등 검사지 개인정보 수집도 줄입니다.

현재 진행 중인 전체 식품 데이터 정제를 마친 뒤 최소 API·로컬 웹 화면을 연결하고, 개인 프로필 입력 화면을 단계적으로 추가합니다.
데이터 정제·식사 계산의 기존 완료 상태는 유지하며 이번에는 방향과 문서만 변경합니다.
