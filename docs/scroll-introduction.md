# 스크롤 서비스 소개 화면

- `/`에서 서비스 소개, `/#dashboard`에서 기존 관리 화면을 표시한다.
- 신체 정보 → 식사 기록 → 영양 해석 순서로 소개한다. 표시하는 200 kcal/100g, 150g, 300 kcal는 연습용이며 실제 식품이나 개인 기록이 아니다.
- 데스크톱에서는 설명을 sticky로 유지하며 옆 카드를 읽는다. IntersectionObserver로 화면에 들어온 카드를 한 번 표시한다. 강제 스크롤이나 스크롤 가로채기는 사용하지 않는다.
- 모바일은 한 열로 표시한다. prefers-reduced-motion에서는 이동·등장 효과 없이 내용을 표시한다. IntersectionObserver가 없어도 내용이 보인다.
- 시작 버튼은 기존 대시보드로 연결한다. 소개 화면으로 뒤로 가도 이미 열린 관리 화면은 숨김 상태로 유지하여 임시 입력을 보존한다. 새로고침 시 데이터 보존 정책은 기존 기능과 같다.
- 라이브러리 추가, 데이터 수집, 외부 공개 배포는 하지 않았다.

## 검증

프런트엔드 TypeScript 검사 및 배포용 빌드 통과. 브라우저 검사는 스크롤 등장, 390px 화면 넘침, 동작 줄이기, 대시보드 진입, 뒤로 가기 및 기존 기능을 포함한다.

실행 결과: `bash scripts/frontend.sh build` 통과, Playwright 전체 **13개 통과(36.9초)**. 데스크톱 1440px·모바일 390px 캡처를 직접 확인했다. 가로 넘침 없음, 카드 등장과 동작 줄이기, 대시보드 이동 및 뒤로 가기 확인. 기존 계정·프로필·식사·영양 분석 시나리오도 통과했다.
