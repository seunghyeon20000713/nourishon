# 펼침 메뉴

N 로고 아래와 관리 화면 우측 상단에 아이콘 전용 메뉴 버튼을 추가했다. 두 버튼은 하나의 펼침 상태를 공유한다. 펼치면 영양 대시보드·식사 분석·기록과 분석·생활 개선·운동 계획·내 몸과 목표 이름을 표시한다.

메뉴 선택 시 해당 화면으로 이동한 뒤 접는다. Escape로 닫고 왼쪽 메뉴 버튼에 키보드 포커스를 돌려준다. 버튼에는 aria-label, aria-expanded, aria-controls를 제공한다. 큰 화면은 펼침 너비에 맞춰 본문을 옮기고, 좁은 화면에서는 메뉴가 본문 위에 표시된다. 모바일의 기존 바로가기 메뉴도 유지한다.

검증: TypeScript 및 Vite 빌드, 실제 브라우저 양쪽 버튼 연동·메뉴명 표시·Escape·화면 이동·390px 가로 넘침 검사를 수행한다. 개인 기록과 인증 조건 변경은 없다.

실제 실행 결과: 빌드 통과, Playwright 전체 **15개 통과(42.4초)**. 데스크톱·모바일 메뉴 캡처를 확인하고 모바일에서 계정 버튼이 펼침 메뉴 위에 겹치지 않도록 표시 순서를 조정했다.

N 그림 로고는 스크롤 소개 화면(`#intro`)으로, NourishOn 글자 로고는 메인 대시보드로 연결한다. 소개 헤더에서도 그림과 글자의 링크를 분리했다. 소개에서 대시보드로 돌아오면 메인 화면을 표시하며 기존 관리 화면의 임시 입력 상태는 유지한다.
