# 펼침 메뉴

N 로고 아래와 관리 화면 우측 상단에 아이콘 전용 메뉴 버튼을 추가했다. 두 버튼은 하나의 펼침 상태를 공유한다. 펼치면 영양 대시보드·식사 분석·기록과 분석·생활 개선·운동 계획·내 몸과 목표 이름을 표시한다.

메뉴 선택 시 해당 화면으로 이동한 뒤 접는다. Escape로 닫고 왼쪽 메뉴 버튼에 키보드 포커스를 돌려준다. 버튼에는 aria-label, aria-expanded, aria-controls를 제공한다. 큰 화면은 펼침 너비에 맞춰 본문을 옮기고, 좁은 화면에서는 메뉴가 본문 위에 표시된다. 모바일의 기존 바로가기 메뉴도 유지한다.

검증: TypeScript 및 Vite 빌드, 실제 브라우저 양쪽 버튼 연동·메뉴명 표시·Escape·화면 이동·390px 가로 넘침 검사를 수행한다. 개인 기록과 인증 조건 변경은 없다.

실제 실행 결과: 빌드 통과, Playwright 전체 **15개 통과(42.4초)**. 데스크톱·모바일 메뉴 캡처를 확인하고 모바일에서 계정 버튼이 펼침 메뉴 위에 겹치지 않도록 표시 순서를 조정했다.

N 그림 로고는 스크롤 소개 화면(`#intro`)으로, NourishOn 글자 로고는 메인 대시보드로 연결한다. 소개 헤더에서도 그림과 글자의 링크를 분리했다. 소개에서 대시보드로 돌아오면 메인 화면을 표시하며 기존 관리 화면의 임시 입력 상태는 유지한다.

## 2026-11-17 메뉴 버튼 하나로 정리 (화면 개선안 A)

화면 점검([design/redesign-2026-11](design/redesign-2026-11/README.md))에서 "같은 일을 하는 버튼이 여러 개라 어디를 눌러야 할지 헷갈린다"는 문제를 찾았다. 햄버거 2개, "내 정보"와 "내 계정" 드롭다운, 계정 패널을 여는 설정 톱니가 겹쳤다.

- 데스크톱: 왼쪽 메뉴 버튼만 남겼다. 상단 메뉴 버튼과 설정 톱니(계정 버튼과 같은 패널을 연다)는 숨겼다.
- 모바일: 상단 바 한 줄(서비스 이름 · 계정 · 기록 설정 · 메뉴)로 정리했다. 왼쪽 메뉴 영역은 펼쳤을 때만 상단 바 아래 목록으로 보인다. 상단 바와 계정 버튼은 스크롤해도 위에 고정된다. "+식사 기록"은 하단 메뉴 "식사"와 같아서 모바일에서는 숨겼다.
- 상단 "내 정보" 드롭다운은 **"기록 설정"**으로 이름을 바꿨다. 메뉴의 "내 정보"(신체 정보 화면)와 이름이 같았고, 실제 내용은 프로필 전환과 저장 설정이다.
- 검증: `menu.spec`을 새 구조로 바꿨다. 데스크톱은 왼쪽 버튼만 보이고, 모바일은 상단 버튼만 보이며, 상단 한 줄 요소가 서로 겹치지 않는지 확인한다. 여러 테스트에 흩어져 있던 "메뉴가 안 보이면 상단 메뉴 버튼 누르기"는 공통 도우미 `goToView`로 바꿨다. 이 도우미는 화면이 그려질 때까지 기다린 뒤 판단한다. 기존 방식은 그리기 전에 판단하는 경쟁 상태가 있었는데, 상단 버튼이 항상 있어서 가려져 있었다.
