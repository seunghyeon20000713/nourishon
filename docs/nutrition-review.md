# 기록된 식사의 영양학적 구성 검토 · 2026-11-06

## 구현

생활 개선 화면의 ‘영양학적 근거로 식사 돌아보기’에서 오늘 기록된 식사 스냅샷을 검토합니다. `/nutrition/review`가 Python 코드로 계산하며 LLM을 사용하지 않습니다. 사용자 기록은 이 검토 요청으로 DB나 외부 디자인 도구에 추가 저장하지 않습니다.

- 탄수화물·단백질은 4kcal/g, 지방은 9kcal/g으로 환산하고, 기록된 표시 열량을 분모로 성분별 에너지 비율을 계산합니다.
- [2025 한국인 영양소 섭취기준 공식 발표](https://www.kns.or.kr/fileroom/fileroom_view.asp?BoardID=Kdr&idx=168)의 일반 성인 에너지 적정비율과 기록 구성을 비교합니다. 비교 결과는 하루 적정성·결핍 진단이 아닙니다.
- 표시 열량이나 다량영양소가 누락됐거나 표시 열량이 0이면 비율 평가를 보류합니다.
- 표시 열량과 4·4·9 환산 열량의 상대 차이가 10%를 넘으면 비교를 보류합니다. 10%는 자료 확인을 위한 프로젝트 규칙이며 공식 영양 판정 기준이 아닙니다. 식이섬유·유기산·산출 방법과 반올림 등으로 차이가 생길 수 있어 원본 오류라고 단정하지 않습니다.
- 스냅샷의 실제 섭취 나트륨 값으로 기여 식품 상위 3개를 표시합니다. 누락된 성분은 기여 순위나 합계에서 0으로 바꾸지 않습니다.
- 확인된 나트륨 값만으로 일반 성인 하루 WHO 참고 기준에 도달하면 다음 식사에서 국물·소스 양을 살펴보도록 안내합니다. WHO 기준과 한국인 섭취기준을 같은 기준으로 표시하지 않습니다.
- 식이섬유 누락은 판단 불가로 표시합니다. 총당류를 유리당 기준과 직접 비교하거나 혈당을 예측하지 않습니다.
- 현재 프로필이 있으면 유지 에너지·일반 단백질 참고값을 함께 표시하되 남은 권장 섭취량이나 감량 열량으로 표시하지 않습니다.

공식 일반 식생활 참고: [WHO Healthy diet](https://www.who.int/news-room/fact-sheets/detail/healthy-diet).

표시 단위 g·mg·kcal를 검증하고 음수·NaN·무한대를 거부합니다. 식품 스냅샷의 consumed 값을 합산하며 전달된 합계는 신뢰하지 않습니다. 과거 기록의 식품 원본을 최신 데이터로 다시 조회하지 않으므로 당시 계산값과 출처를 보존합니다. 식품별 스냅샷이 없는 오래된 기록은 상세 검토를 보류하고 기존 합계를 유지합니다.

## 디자인 도구 확인

플러그인 검색에서 Figma·Product Design이 설치되어 있음을 확인했고 Figma 인증 확인도 통과했습니다. 추가 설치는 하지 않았습니다. 이번 작업에서 디자인 파일을 생성하거나 개인 기록·인증키·스크린샷을 외부 디자인 도구에 업로드하지 않았습니다. 전체 화면 스타일은 사용자의 방향 선택 후 시안을 비교해 별도 적용합니다.

## 검증

가상 식품 스냅샷으로 정상 비율, 부분·전체 결측과 숫자 0, 열량 불일치, 잘못된 단위, 나트륨 기여 식품과 누락 상태의 기준 도달을 검증합니다. 실제 브라우저에서 60% 비율과 연습용 식품 기여량, 불일치 시 평가 보류 및 390px 화면을 확인합니다. 식사 구성 비교의 임상적 타당도나 사용자 건강 개선 효과를 검증했다고 주장하지 않습니다.

실제 실행 결과: 전체 백엔드 90개 통과, 브라우저 11개 시나리오 통과, TypeScript 검사·Vite 빌드 통과. 디자인 플러그인의 설치·Figma 인증 상태는 확인했으며, 전체 스타일 개편은 아직 수행하지 않았습니다.
