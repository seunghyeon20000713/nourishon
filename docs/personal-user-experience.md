# 개인 사용자 중심 화면·계정 흐름 개선

확인일: 2026-11-06. 기존 초록·흰색 디자인과 계산·저장 기능을 유지하고 개인 사용자의 반복 작업을 우선했다. 외부 배포는 이번 범위가 아니다.

## 참고한 실제 서비스의 공식 사용 안내

- [MyFitnessPal Today](https://support.myfitnesspal.com/hc/en-us/articles/39985611667341-Your-Today-tab): 일일 기록을 홈에 두고 자주 쓰는 기록 동작에 빠르게 진입하는 흐름을 참고했다.
- [Cronometer Diary](https://support.cronometer.com/hc/en-us/articles/360018171731-Diary-Overview): 날짜별 식사·활동·측정 항목 진입과 요약 구성을 참고했다.
- [YAZIO Tutorial](https://help.yazio.com/hc/en-us/articles/11804776635281-Tutorial-of-the-Yazio-app): 일일 기록과 기간 분석, 프로필·설정의 역할 분리를 참고했다.

공식 도움말로 사용 흐름을 확인한 연구이며 해당 서비스의 로그인 후 화면을 직접 사용성 평가한 것은 아니다. 브랜드·화면·영양 점수·단식·운동 열량 상쇄 기능을 그대로 복제하지 않았다.

## 기존 화면 점검과 조치

1. **계정 진입**: 로그인 전에도 ‘내 계정’ 표시가 있어 상태를 알기 어려웠다. ‘로그인 / 회원가입’으로 바꾸고 선택 버튼 두 개와 하나의 입력 폼을 제공한다. 로그인·가입 후에는 ‘내 계정’, 펼치면 사용자 아이디와 로그아웃이 보인다. 모드 전환 시 입력 폼을 새로 만들어 비밀번호가 다른 모드에 남지 않게 한다.
2. **내 정보**: 다중 프로필 생성 폼이 첫 화면에 노출되어 본인 정보 수정 경로가 불분명했다. ‘내 정보 수정’을 먼저 제공하고 프로필 전환·추가는 접힌 항목에 둔다. 기존 프로필·선택 상태·개인 기록을 삭제·병합하지 않는다. 여러 프로필이 있으면 현재 선택을 표시한다.
3. **홈 기록 진입**: 상세 분석보다 먼저 식사·운동·신체 정보 바로가기를 제공한다. 실제 기록 건수·운동 시간·선택일까지 최근 체중만 표시한다. 미기록과 0을 구분하며 과거 날짜에 미래 측정값을 넣지 않는다. 운동 기록 버튼은 긴 주간 계획 입력을 건너뛰어 실제 운동 기록 위치로 이동한다.
4. **모바일 탐색**: 좁은 영역의 작은 6개 메뉴 대신 오늘·식사·기록·운동을 하단에 제공한다. 생활 개선·내 몸과 목표 등 전체 메뉴는 기존 햄버거 버튼으로 접근한다. 메뉴를 펼친 동안 하단을 숨겨 같은 동작이 중복 노출되지 않게 한다. 하단 고정 메뉴가 본문을 가리지 않도록 여백을 둔다.
5. **저장 안내**: DB·PostgreSQL 대신 ‘계정 기록 · 저장 완료’, ‘기록 저장 중’, ‘서버 기록 다시 불러오기’ 등 사용자에게 필요한 동작 중심 용어로 바꿨다. 실패·충돌·로컬 기록의 미업로드 안내는 유지한다.

## 화면 증거와 한계

이번 작업에서 새 비로그인 브라우저 세션으로 홈·계정·프로필의 변경 전 화면을 캡처해 직접 확인했다. 변경 후 데스크톱·390px 모바일·계정 화면과 실제 탐색을 검증했다. 캡처는 `/tmp/nourishon-personal-before-*.png`, `/tmp/nourishon-personal-after-*.png`로 로컬에만 보관한다. 실제 개인 건강정보를 사용하지 않았다.

스크린샷만으로 접근성 준수를 단정하지 않는다. 키보드 Escape·포커스 복귀, 로그인 선택 상태, 실제 가입·로그인, 프로필 데이터 보존·전환, 모바일 탐색은 브라우저 검사로 확인한다. 실제 지인의 과업 성공률이나 사용 만족도는 아직 측정하지 않았다.

## 실제 검증 결과

- TypeScript·Vite 빌드 통과.
- 전체 Playwright **21개 통과(35.7초)**. 실제 가입·로그인·로그아웃, 상태 문구, 계정 DB 기록, 다중 프로필 보존·전환, 내 정보 바로가기, 운동 기록 위치 이동·포커스, 모바일 하단 메뉴와 가로 넘침, 기존 기록 기능 포함.
- 최초 실행의 모바일 검사 2개는 숨겨진 전체 메뉴를 곧바로 누르려다 실패했다. 햄버거로 전체 메뉴를 먼저 여는 변경된 사용자 흐름으로 검사를 수정하고 전체 재검증을 통과했다.
- 변경 전후 계정 화면을 같은 1440×1000 뷰포트의 이미지로 함께 비교했다. 로그인 선택의 구분, 계정 상태 표시, 새 카드와 기존 색상·간격을 확인했다. 모바일은 390×844 환경에서 하단 메뉴·가로 넘침을 확인했다.
- 점검 단계별 결과: 계정 진입 정상, 내 정보 수정 정상, 기존 프로필 전환 정상, 홈 빠른 기록 정상, 모바일 탐색 정상. 사용자 연구를 통한 편의성 향상 수치는 아직 없다.
