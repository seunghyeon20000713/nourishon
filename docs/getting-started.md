# 첫 이용 안내

대시보드에 선택한 프로필 기준의 안내를 추가했다.

1. 프로필 등록 여부: `profile` 존재 여부
2. 추정 목표 계산 여부: `profile`과 `estimate` 존재 여부
3. 첫 식사 기록 여부: `records`가 한 개 이상인지 확인

안내는 데이터로 계산하며 별도의 완료 플래그를 저장하지 않는다. 목표가 계산됐다는 표시가 사용자의 근거 확인이나 목표 달성을 뜻하지 않는다. 미완료 첫 단계를 다음 할 일로 표시하되 입력 순서를 강제하지 않는다. 모두 등록되면 안내를 접고, 사용자가 다시 펼칠 수 있다. 기록이 삭제되거나 프로필이 바뀌면 해당 데이터 상태를 반영한다.

버튼은 기존 프로필·참고 목표·식사 입력 화면으로 연결한다. 새 계정이나 개인 정보를 자동 생성하지 않는다. 로그인 없이 시작할 수 있으며 계정 저장과 브라우저 로컬 저장은 별도임을 안내한다. 서버에 저장 중이거나 실패한 경우 기존 전역 저장 상태 표시를 확인해야 한다. 이 안내의 등록 표시는 DB 저장 완료 보장이 아니다.

검증: TypeScript 및 Vite 빌드 통과. 실제 로컬 API를 사용하는 브라우저 시나리오로 프로필 입력 → 목표 계산 → 근거 화면 → 음식 검색 → 계산 → 첫 기록 → 안내 접힘과 모바일 가로 넘침을 검사한다.

실제 실행 결과: 빌드 통과, Playwright 전체 **14개 통과(39.3초)**. 첫 이용 안내를 통한 실제 프로필·식사 API 연결과 기존 계정·스크롤 소개·영양 분석 검사를 포함한다.
