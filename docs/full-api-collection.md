# 공공 API 전체 수집

실행일: 2026-11-05. Python 3.12.3 가상환경, 외부 라이브러리 설치 없음.

## 범위와 공식 출처

[식약처 식품영양성분DB API](https://www.data.go.kr/en/data/15127578/openapi.do)를 분류·음식명 등 필터 없이 조회합니다.
‘전체’는 해당 API가 이번 실행에서 제공하는 전체 결과 범위이며 모든 기관의 모든 식품을 의미하지 않습니다.
기존 100개 표본과 별도 폴더에 원본을 보존합니다. 정제나 계산을 위해 일부 기준량만 골라도 이번 원본 수집에서는 제외하지 않습니다.

## 실행과 이어받기

```bash
.venv/bin/python -B -m backend.collect_all_food_api \
  data/raw/mfds-api-full-20261105-size500 --size 500
```

처음에는 새 폴더를 만들고, 같은 명령을 다시 실행하면 기록된 페이지의 해시·건수·연속성을 확인한 뒤 빠진 페이지부터 이어받습니다.
수집이 완료된 폴더에서는 API를 다시 호출하지 않고 저장된 전체 파일을 재검증합니다. 최신 데이터를 다시 수집하려면 새 폴더를 사용합니다.
명령을 실행할 때만 동작하며 자동 주기 실행은 없습니다. 인증키는 `.env`에서 읽고 출력하지 않습니다.

- 기본 페이지 크기는 실제 정상 응답을 확인한 500개입니다. 100개 단위도 확인했습니다. 1,000개 단위는 정상 응답이 아니어서 사용하지 않습니다. 이를 공식 최대 한도 확정으로 해석하지 않습니다.
- 동시 요청은 최대 3개로 제한하고 페이지 처리 사이 간격을 둡니다. 요청 실패 시 최대 3회 시도하고 계속 실패하면 중단합니다.
- 원본은 `page-00001.json`부터 저장하고 `manifest.json`에는 키 없는 요청 주소, 페이지 크기·전체 건수·수신 건수·파일 해시·진행 상태를 기록합니다.
- 진행 기록은 임시 파일에 쓴 뒤 교체합니다. 원본 저장 직후 기록 전에 중단된 페이지도 재개 시 내용 검증 후 복구합니다.
- 원본 파일은 덮어쓰지 않습니다. 페이지 크기를 바꿀 때는 새 수집 폴더를 사용합니다.
- 모든 페이지의 전체 건수 일치, 페이지별 예상 수신 건수, 식품코드 유무·중복을 검증합니다.
- 완료 조건은 실제 수신 건수 = 보고된 전체 건수 = 고유 식품코드 수입니다. 하나라도 불일치하면 완료로 표시하지 않습니다.
- 중간 실패·수동 중단은 `interrupted_or_failed`, 전체 검증 완료는 `completed`와 `full_collection_complete: true`입니다.
- 수집 중 데이터가 바뀔 수 있습니다. 전체 건수가 변하면 중단합니다. 건수가 같아도 값이 바뀌는 경우까지 막는 서버 스냅샷 기능은 확인되지 않았으므로 특정 순간의 불변 스냅샷이라고 주장하지 않습니다.

## 공개 범위

데이터·수집 기록·`.env`·인증키는 Git 제외 상태로 로컬에 보관합니다.
코드·가상 응답 테스트·실행 방법·검증 집계만 공개합니다. 실패 응답이나 키를 포함한 URL은 출력하지 않습니다.
전체 수집 완료는 영양성분의 결측 없음이나 과학적 정확성 검증을 뜻하지 않습니다.
