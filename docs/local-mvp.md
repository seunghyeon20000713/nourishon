# 로컬 MVP · 2026-11-05

## 직접 확인하기

백엔드와 프론트엔드를 실행하고 http://127.0.0.1:5173/ 를 엽니다.

1. 내 몸과 목표에서 가상의 일반 성인 정보를 입력하고 참고 목표를 계산합니다.
2. 식사 분석에서 음식을 검색하고 실제 섭취량을 계산한 뒤 식사 기록에 추가합니다.
3. 기록과 분석에서 날짜별 합계와 최근 7일 기록 현황을 확인합니다.
4. 생활 개선에서 기록과 공식 자료에 따른 안내를 확인합니다.

기본은 메모리에 유지하므로 새로고침하면 초기화됩니다. 브라우저 보관을 선택하면 localStorage에 암호화 없이 남습니다. 보관 해제는 저장 사본을 지우며 현재 화면의 기록은 유지합니다. 이후 새로고침하면 초기화됩니다. 서버는 요청 계산만 수행하며 프로필·식사를 파일이나 DB에 저장하지 않습니다. 공개 서비스용 인증·접근제어는 아직 없습니다.

## 계산과 적용 대상

19~64세 일반 성인으로 범위를 제한합니다. 임신·수유, 치료식, 재활, 전문 운동선수 관리는 제외합니다. 입력 범위는 제품의 검증 범위이며 의학적 정상 범위가 아닙니다.

- BMI = 체중(kg) / 키(m)의 제곱. 체지방·근육·건강 상태를 단독 판정하지 않습니다.
- 추정 유지 에너지: NASEM DRI Energy 2023의 성별·활동별 성인 공식. 나이(세), 키(cm), 체중(kg)을 사용합니다. 감량·증량 방향을 선택해도 자동 열량 가감은 하지 않습니다. 한국인 영양소 섭취기준에 기반한 처방으로 표시하지 않습니다.
- 일반 단백질 참고값: 체중 1kg당 하루 0.8g. 운동선수나 질환 관리 목표가 아닙니다.
- WHO 일반 참고: 식이섬유 하루 25g 이상, 나트륨 하루 2,000mg 미만.
- 총당류는 유리당과 다르므로 WHO 유리당 비율 기준과 비교하지 않습니다.
- 인바디 입력은 현재 측정값 등록용이며 에너지 공식에 사용하지 않습니다. 측정 이력·추세와 운동 처방은 다음 단계입니다.

공식 원문과 활동 구분 설명:

- [Health Canada: DRI 2023 유지 에너지 공식](https://www.canada.ca/en/health-canada/services/food-nutrition/healthy-eating/dietary-reference-intakes/tables/equations-estimate-energy-requirement.html)
- [HealthLink BC: 일반 성인 단백질 참고](https://www.healthlinkbc.ca/healthlinkbc-files/protein-and-your-health)
- [WHO: Healthy diet](https://www.who.int/news-room/fact-sheets/detail/healthy-diet)
- [WHO: 2020 신체활동 지침](https://www.who.int/europe/news-room/fact-sheets/item/physical-activity)

## 기록과 제안 설계

식사 기록은 계산 응답 전체를 보관하여 당시 식품명·섭취량·출처·값을 유지합니다. 데이터 갱신으로 과거 합계를 자동 재계산하지 않습니다. 날짜별 합계는 확인된 값만 더하고 누락 수를 유지합니다. 미기록일은 0이 아닙니다. 일부 식사 기록으로 하루 결핍을 진단하지 않습니다.

현재 안내는 코드의 규칙과 공식 일반 지침을 사용합니다. 확인된 나트륨 합계가 참고 상한 이상이면 국물·소스 줄이기를 안내하며, 식이섬유 누락은 평가 불가로 표시합니다. 가격·재고·알레르기 적합성을 추정하지 않습니다. 운동은 일반 활동 지침이며 개인 운동 처방이 아닙니다. LLM·RAG·유료 API를 사용하지 않습니다.

## 검증과 오류 해결

가상 프로필로 8개 성별·활동 공식, BMI, 인바디 입력 전후 동일 에너지, 음수·비정상·범위 밖 입력을 검증합니다. 가상의 30세·170cm·70kg 비활동 남성은 유지 에너지 2,520kcal, BMI 24.22, 단백질 참고 56g입니다. 여성 공식은 2,167kcal입니다.

브라우저에서는 실제 식품 검색·계산과 가상 프로필 등록·기록·선택 보관·새로고침·보관 해제를 검증합니다. 새 API 반영 때 이전 서버가 계속 실행돼 새 경로를 찾지 못한 문제는 개발 서버를 새 코드로 재시작해 해결했습니다. 메뉴가 늘어난 뒤 모바일 가로 넘침은 메뉴 줄바꿈으로 해결했습니다. 첫 계산 테스트의 수기 예상값 오류는 원문 계수를 다시 대입하여 수정했습니다.

최종 실행 결과: 프로젝트 `.venv/bin/python`의 unittest 65개 통과, Playwright 브라우저 시나리오 7개 통과, TypeScript 검사와 Vite 빌드 통과. 모바일 390px의 식사·프로필·기록·생활 개선 메뉴 가로 넘침도 검사했습니다. 사용자 수요·체중 변화·추천 효과는 측정하지 않았습니다.
