# 지인용 Sites 화면 체험판

- 공개 주소: https://nourishon-demo-seunghyeon.cappedaura1.chatgpt.site
- Sites 프로젝트: `appgprj_6aed69eb84208191ae404fa2436e5883`
- 공개 버전: 1
- Sites 소스 커밋: `8f56566ccb5989a083a75ed83d9313e5cb723942`
- 범위: 사용자가 선택한 가상 데이터 기반 화면 체험. 링크를 가진 누구나 접근하도록 승인받아 공개했다.

## 체험할 수 있는 것

스크롤 소개 → 메인 이동, 계정·내 정보 메뉴, 가상 식품 6개 검색·섭취량 계산·식사 기록, 프로필·측정 이력, 주간·월간 분석, 미리 만든 가상 주간 활동 계획, 공개 MET 25개 조건의 브라우저 계산·운동 기록과 모바일 탐색을 체험한다.

가입·로그인·서버 저장·공공 API 연결·LLM은 제공하지 않는다. 실제 기능 서버를 연결했다고 표시하지 않는다. 체험판의 간이 계산은 화면 흐름을 위한 것이며 로컬 Python 계산·검증과 동일한 구현이라고 보장하지 않는다. 실제 식품·개인별 영양 평가에 사용하지 않는다.

## 개인정보와 데이터 분리

화면 상단에 체험판·가상 데이터·로그인/서버 저장 없음·실제 개인정보 입력 금지를 표시한다. 입력은 브라우저 내에서 처리한다. `/api/` 호출을 체험 응답으로 처리하고 실제 백엔드로 보내지 않는다. 체험 기록은 별도 localStorage 키 `nourishon-demo-v1`에만 저장되며, 일반 개발 버전 키와 분리한다. 다른 방문자의 기록은 공유하지 않는다. ‘체험 초기화’로 해당 체험 키만 지운다.

배포 소스는 선택한 프런트엔드 파일만 별도 `sites-preview/` 체크아웃으로 준비했다. `.env`, 인증키, 백엔드, 실제 식품 원본·정제본, 실제 계정·건강 기록, PostgreSQL은 포함하지 않았다. 출처가 있는 공개 MET와 명시적으로 만든 가상 프로필·식품만 포함한다. 최종 배포 압축파일 139개 경로를 검사했다.

## 모드와 재현

일반 빌드: `bash scripts/frontend.sh build`
체험 빌드: `bash scripts/frontend.sh build -- --mode demo --outDir dist-demo`

체험판 소스는 `frontend/src/demoApi.ts`, `demoData.json`, `demo.css`다. Vite의 demo 모드에서만 체험 초기화·가상 응답을 활성화한다. 일반 JS 번들에 체험 데이터와 API 가로채기 코드가 들어가지 않음을 확인했다. `.gitignore`로 체험 빌드와 별도 Sites 체크아웃을 제외한다. Sites 자격 증명은 파일·Git·로그에 저장하지 않고 세션 메모리에서 helper stdin으로만 전달했다.

체험 검증: `NOURISHON_DEMO_URL=<공개 주소> node scripts/check-demo.mjs`. Playwright 브라우저와 이 환경의 브라우저 의존 경로가 필요하다.

## 실제 검증

일반·체험·Sites 체크아웃 빌드 통과. Sites가 공개 배포 성공과 주소를 반환했다. 공개 주소를 인증 정보 없는 새 브라우저에서 직접 열어 소개 → 가상 검색/계산/기록 → 월간 분석 → 러닝 기록 → 모바일을 확인했다. 브라우저 오류 0건, 실제 `/api/` 네트워크 요청 0건, 390px 가로 넘침 없음. 배포 후 캡처도 직접 확인했다.

이 체험판은 사용자 실제 건강정보를 수집하는 운영 서비스가 아니다. 다음 단계의 실제 기능 테스트에는 별도 테스트용 백엔드·DB·HTTPS·인증 운영 설정과 배포 검증이 필요하다.

일반 개발 버전 집중 회귀 검사: 소개·개인 홈/계정 시나리오 **2개 통과(4.5초)**. 체험판을 위한 별도 모드가 일반 실행의 계정·기록 흐름을 변경하지 않음을 확인했다.
