# 신체 측정 기록 수정·삭제

‘내 몸과 목표’ 아래 측정 이력 표에 수정·삭제 버튼을 추가했다.

- 수정 항목: 측정일, 체중, 선택 항목인 골격근량·체지방량·체지방률.
- 선택 값을 비우면 미등록으로 저장한다. 체지방량·체지방률의 0과 미등록을 구분한다. 골격근량은 기존 서버 규칙대로 양수만 허용한다.
- `/measurements/validate`는 계정 저장과 동일한 Measurement 모델로 날짜·체중·체성분 합계를 검증한다. 이 API는 기록을 저장하지 않는다. 로그인 상태의 실제 저장은 기존 소유권·CSRF·리비전 검사를 거치는 계정 API가 담당한다.
- 검증 API도 응답 캐시 금지와 요청 크기 제한을 적용하며, 오류에 입력된 건강 정보를 되돌려 표시하지 않는다.
- 잘못된 값, 연결 실패, 취소 시 원본은 유지한다. 화면 이탈·취소 시 검증 요청을 중단한다.
- 삭제는 날짜를 포함한 확인창 후 선택한 기록 한 건에만 적용한다. 표와 변화 그래프를 즉시 갱신한다.
- 이력 수정·삭제는 현재 프로필, 영양 목표, 운동 계획을 자동으로 변경하지 않는다. 화면에 이를 안내하고 목표 수정은 프로필 재적용으로 구분한다.
- 로그인 시 PostgreSQL에 저장하고, 비로그인 시 기존 로컬 보관 설정을 따른다. 실제 저장 성공 여부는 기존 전역 DB 상태를 확인한다.

## 검증

API 검사: 0과 결측 구분, 미래 날짜·범위 초과·체성분 합계 오류 거절, 입력 비노출 및 캐시 금지.
브라우저 검사: 수정 취소, 잘못된 체성분 거절, 체중 수정, 빈 항목과 0 구분, 목표 유지, 삭제 취소·확정, 모바일 넘침, DB 수정 후 재조회.

실제 실행 결과: TypeScript·Vite 빌드 통과, API·계정 Python 검사 **23개 통과(2.487초)**, 브라우저 전체 **17개 통과(42.6초)**. 검증·수정·삭제 취소·확정 및 DB 재조회 시나리오를 포함한다.
